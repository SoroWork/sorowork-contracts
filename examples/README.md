# Contract Interaction Examples

TypeScript examples showing how to interact with SoroWork Soroban contracts using `@stellar/stellar-sdk`.

## Files

- `create-bounty.ts` — Post a new community task with USDC reward locked in escrow
- `submit-work.ts` — Submit photo evidence for a completed task

## Prerequisites

```bash
npm install @stellar/stellar-sdk
```

## Usage

These are reference examples. Replace `YOUR_BOUNTY_ESCROW_CONTRACT_ID` with your deployed contract address from `DEPLOYED.md`.
